# Dataset Information

## Dataset Name
EU Superstore Sales

## Purpose
The dataset is used for sales performance analysis and dashboard development in Tableau.

## Fields Used
- Order Date
- Order ID
- Customer Name
- Segment
- Country/Region
- Region
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

## Data Source
The dataset was obtained from Tableau's sample data resources.

Please consult the original dataset source for applicable usage and attribution terms.

## Data Handling
The Tableau dashboard is saved as a packaged workbook (`.twbx`) which may contain an embedded copy of the data.
