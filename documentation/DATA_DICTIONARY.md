# SalesPulse Data Dictionary

| Field | Description |
|---|---|
| Order Date | Date when an order was placed |
| Ship Date | Date when an order was shipped |
| Order ID | Unique order identifier |
| Customer ID | Customer identifier |
| Customer Name | Name of the customer |
| Segment | Customer segment |
| Country/Region | Country or geographical area |
| Region | Sales region |
| Category | Product category |
| Sub-Category | Product sub-category |
| Product Name | Product description/name |
| Sales | Sales amount |
| Quantity | Units sold |
| Discount | Discount applied |
| Profit | Profit amount |

## KPI Definitions

- **Total Sales:** Sum of Sales.
- **Total Profit:** Sum of Profit.
- **Total Orders:** Distinct count of Order ID.
- **Profit Margin:** Total Profit divided by Total Sales.
- **Average Order Value:** Total Sales divided by distinct Order ID count.

## Notes

Field definitions are based on the dataset fields used in the Tableau workbook.
