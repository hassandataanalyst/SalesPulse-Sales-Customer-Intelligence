# SalesPulse Dashboard QA Checklist

## Data Validation
- [ ] Sales KPI matches the underlying dataset.
- [ ] Profit KPI matches the underlying dataset.
- [ ] Orders KPI uses distinct Order IDs.
- [ ] Profit Margin calculation is correct.
- [ ] Average Order Value calculation is correct.

## Dashboard Design
- [ ] Dashboard size is 1200 × 750.
- [ ] Header is aligned.
- [ ] KPI cards are aligned and readable.
- [ ] Chart titles are consistent.
- [ ] Dark theme is consistent.
- [ ] No chart or filter is clipped.

## Interactivity
- [ ] Year filter works.
- [ ] Category filter works.
- [ ] Segment filter works.
- [ ] Region filter works.
- [ ] All filters show the expected data.
- [ ] All selections can be reset to All.

## Publishing
- [ ] Packaged workbook opens correctly.
- [ ] Dashboard screenshot is included.
- [ ] README contains dashboard preview.
- [ ] Tableau Public link is correct.
- [ ] GitHub repository is public.
